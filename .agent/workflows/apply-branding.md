# Workflow: Apply VoiceAgent Branding

1.  **Extract Design Tokens**: Analyze `VoiceAgents.mhtml` for colors and fonts.
2.  **Import Fonts**: Add Poppins, Inter, Plus Jakarta Sans to `layout.jsx`.
3.  **Define CSS Variables**: Update `globals.css` with HEX codes and font assignments.
4.  **Update Application Context**: Set `app_name`, `welcome_message`, and default theme (light).
5.  **Refactor Components**: Update `Layout.jsx` and `LoginPage.jsx` with the branded logo and accents.
6.  **Set Primary Font**: Ensure `Poppins` is the global default as per user request.
7.  **Verify**: Perform visual (if possible) and manual code checks.
